Conexión de Datos (Back Office)

Configure la fuente de datos externa (Google Sheets) para actualizar la información de forma automática.

Pasos para conectar su Google Sheet:

  1. Abra su hoja de cálculo de Google Sheets con las dos pestañas de control.
  2. Vaya al menú superior: Archivo -> Compartir -> Publicar en la Web.
  3. En la ventana de publicación:
    • Seleccione la pestaña de Cilindros (Control Mensual Agosto) y elija formato Valores separados por comas (.csv).
    • Copie el enlace generado y péguelo en el campo CSV de Cilindros abajo.
    • Haga lo mismo para la pestaña de Pruebas PH (Control Mensual de Agosto), copiando el enlace en el campo CSV de PH.
  4. Presione "Guardar y Conectar". ¡El dashboard se actualizará dinámicamente usando estas fuentes!
